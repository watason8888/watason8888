# Windows セットアップガイド（詳細版）

## 全体の流れ

```
Step1: Pythonインストール
Step2: ライブラリインストール
Step3: アプリパスワード取得・バッチファイル設定
Step4: 手動テスト
Step5: タスクスケジューラで毎朝6時に自動化
```

---

## Step 1：Pythonのインストール

1. [https://www.python.org/downloads/](https://www.python.org/downloads/) を開く
2. 「Download Python 3.x.x」ボタンをクリックしてダウンロード
3. インストーラーを起動
   - **⚠️ 重要：** 「Add Python to PATH」に**必ずチェックを入れる**
4. 「Install Now」をクリック

インストール確認（コマンドプロンプトで）：
```cmd
python --version
```
`Python 3.x.x` と表示されればOKです。

---

## Step 2：ライブラリのインストール

1. **コマンドプロンプト**を開く（Windowsキー → `cmd` と入力 → Enter）
2. `news-digest` フォルダに移動：

```cmd
cd C:\Users\あなたのユーザー名\Desktop\news-digest
```

3. ライブラリをインストール：

```cmd
pip install feedparser
```

---

## Step 3：アプリパスワードの取得と設定

### Gmailアプリパスワードの取得

1. Googleアカウント（wkoki2000@gmail.com）にログイン
2. [https://myaccount.google.com/security](https://myaccount.google.com/security) を開く
3. **「2段階認証プロセス」** を有効化（未設定の場合のみ）
4. 2段階認証のページを開き、一番下にある **「アプリパスワード」** をクリック
5. アプリ名に `ニュースダイジェスト` と入力 → **「作成」**
6. 表示された **16文字のパスワード**（例：`abcd efgh ijkl mnop`）をメモ

### バッチファイルへの設定

`run_news_digest.bat` をメモ帳で開き、以下の行を書き換えます：

```bat
set GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx
```

↓ 取得した16文字に変更（スペースありのままでOK）

```bat
set GMAIL_APP_PASSWORD=abcd efgh ijkl mnop
```

保存して閉じます。

---

## Step 4：手動テスト

`run_news_digest.bat` をダブルクリックして実行します。

- 黒い画面が一瞬出て閉じれば正常です
- `news_digest.log` ファイルが生成され `[OK] 送信完了` と書かれていれば成功
- `wkoki2000@gmail.com` にメールが届いていることを確認

---

## Step 5：タスクスケジューラで毎朝6時に自動実行

### 設定手順

1. Windowsキー を押して `タスクスケジューラ` と入力 → Enterで起動

2. 右側の「**タスクの作成**」をクリック

3. **「全般」タブ**
   - 名前: `毎朝ニュースダイジェスト`
   - 「**ユーザーがログオンしているかどうかにかかわらず実行する**」を選択
   - 「**最上位の特権で実行する**」にチェック

4. **「トリガー」タブ** → 「新規」
   - タスクの開始: `スケジュールに従う`
   - 設定: `毎日`
   - 開始: 日付は今日、時刻は `6:00:00`
   - 「OK」

5. **「操作」タブ** → 「新規」
   - 操作: `プログラムの開始`
   - プログラム/スクリプト: バッチファイルのフルパスを入力
     例: `C:\Users\あなたのユーザー名\Desktop\news-digest\run_news_digest.bat`
   - 「OK」

6. **「条件」タブ**
   - 「**コンピューターをAC電源で使用している場合のみタスクを開始する**」の**チェックを外す**
   （ノートPCの場合、バッテリー駆動中でも動くようにするため）

7. **「設定」タブ**
   - 「**タスクを要求時に実行する**」にチェック

8. 「OK」→ Windowsのパスワードを求められたら入力

### 動作確認

設定したタスクを右クリック → **「実行」** で即時テスト実行できます。

## ログの確認方法

`news-digest` フォルダ内の `news_digest.log` をメモ帳で開くと、
毎回の実行結果が記録されています。

```
==========================================
実行日時: 2026/03/13 06:00:01
==========================================
[INFO] ニュース収集開始 (2026-03-13 06:00)
[INFO] 収集完了: 合計 47 件
[OK] 送信完了: wkoki2000@gmail.com  (06:00:23)
```

## よくあるトラブル

| 症状 | 対処法 |
|------|--------|
| `python` が認識されない | Pythonインストール時に「Add to PATH」のチェックを確認。再インストールを推奨 |
| `SMTPAuthenticationError` | アプリパスワードが間違い。Googleアカウントで再発行して設定し直す |
| タスクが実行されない | タスクスケジューラの「条件」タブで「AC電源のみ」チェックを外す |
| メールが届かない | `news_digest.log` を確認。エラー内容をそのままお知らせください |
| 記事が0件 | ネット接続・Windowsファイアウォールの設定を確認 |
